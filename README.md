# AI Data Analyst Mode

A powerful Streamlit application that allows users to upload datasets and ask analytical questions in natural language. The AI acts as a data analyst, breaking down questions into multiple analysis steps and generating Python code to investigate the data.

## Features

- **Dataset Upload**: Support for CSV and Excel files
- **Automatic Dataset Summary**: View shape, columns, data types, missing values, and sample rows
- **Natural Language Queries**: Ask questions like "Why are sales dropping?" or "What factors affect customer churn?"
- **AI-Powered Analysis**: Gemini API generates multiple investigation steps
- **Code Generation**: Automatically generates Python code using pandas, matplotlib, and seaborn
- **Visualization**: Charts are generated and displayed inline
- **Insights**: AI explains findings and provides actionable recommendations
- **Chat Interface**: Continue with follow-up questions

## Installation

1. **Clone or navigate to the project directory**:
   ```bash
   cd ai_data_analyst
   ```

2. **Create a virtual environment** (recommended):
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Set up environment variables**:
   ```bash
   # Copy the example file
   cp .env.example .env
   
   # Edit .env and add your Gemini API key
   # Get your API key from: https://aistudio.google.com/app/apikey
   ```

## Running the Application

1. **Start the Streamlit server**:
   ```bash
   streamlit run app/main.py
   ```

2. **Open your browser**:
   - The app will open at `http://localhost:8501`

## How to Use

1. **Upload a Dataset**:
   - Click on "Upload Dataset" in the sidebar
   - Select a CSV or Excel file
   - The dataset will be automatically loaded and summarized

2. **Ask Questions**:
   - Enter your Gemini API key in the sidebar
   - Type a question in the chat input
   - Examples:
     - "Why are sales dropping?"
     - "What factors affect customer churn?"
     - "Which products perform best?"
     - "Show sales by region"
     - "Find the top 10 customers"

3. **View Results**:
   - See the analysis steps generated by AI
   - View the generated Python code
   - Check the visualizations
   - Read the insights and recommendations

4. **Follow-up Questions**:
   - Continue the conversation with more specific questions
   - The AI maintains context of previous analysis

## Troubleshooting

**API Key Error**: Make sure your Gemini API key is set in the `.env` file or entered in the sidebar.

**File Loading Error**: Ensure your file is in CSV (.csv) or Excel (.xlsx, .xls) format and not larger than 50MB.

**Code Execution Error**: The generated code runs in a sandbox. Some advanced operations may be restricted for security.
